# Portal Estudiantil

Proyecto de aplicación web SPA para informar a los estudiantes sobre talleres y permitir la inscripción en línea. Desarrollado con Angular.

## Estructura de Commits
1. `commit 1: estructura base del proyecto` - Creación del proyecto y componentes base.
2. `commit 2: rutas y navegacion` - Configuración de Angular Router y rutas.
3. `commit 3: formulario de inscripcion y validaciones` - Formulario reactivo y validaciones.
4. `commit 4: estilos css y entrega final` - Estilos finales y compilación.

## Cómo ejecutar el proyecto
1. Instalar paquetes:
   ```bash
   npm install
   ```
2. Iniciar servidor:
   ```bash
   npm start
   ```
3. Abrir navegador en `http://localhost:4200`
